ОПИС АРХІТЕКТУРИ
-----------------------------------------------------------------------------
Система складається з двох ізольованих частин, які працюють у зв'язці:
1. Python-скрипт (Data Pipeline + AI + Scraper) - обробляє сирі файли постачальника, парсить відсутні фото, генерує SEO-контент через OpenAI.
2. PHP-модуль (OpenCart) - кастомний контролер, який імпортує підготовлені Python-ом файли в базу даних магазину (товари, опції, атрибути, категорії).


ЧАСТИНА 1: PYTHON (app.py)
-----------------------------------------------------------------------------
Стек: Python 3.9+, Streamlit, Pandas, BeautifulSoup4, Cloudscraper, OpenAI.

1. Запуск та Інтерфейс:
   - Запускається локально командою: `streamlit run app.py`
   - UI побудований на фреймворку Streamlit. Дозволяє завантажувати базові файли постачальника, обирати ліміти та вмикати/вимикати ШІ.

2. Перемінні оточення (.env):
   Для роботи скрипта потрібен файл `.env` у кореневій папці з такими ключами:
   OPENAI_API_KEY=sk-...
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
   TELEGRAM_CHAT_ID=123456789

3. Логіка роботи (Що під капотом):
   - Фільтрація: Скрипт автоматично відкидає товари зі статусом "Немає в наявності" (якщо стоїть відповідна галочка).
   - Скрейпінг категорій: Використовується `cloudscraper` для обходу Cloudflare на сайті moto-motion.com.ua. Збираються фото категорій. Зіставлення назв (Excel <-> Сайт) відбувається через Fuzzy Match (модуль `difflib` з порогом збігу 0.55).
   - Генерація SEO (ChatGPT): Для батьківських моделей генеруються унікальні SEO-тексти, мета-теги та ключові слова. Промпт налаштований на експертний tone-of-voice та генерацію HTML-розмітки (<ul>, <li>, <p>).
   - Кешування (Автозбереження): Щоб уникнути втрати грошей на API та часу при збоях, скрипт зберігає кожен згенерований опис у `ai_cache.json` та `cat_cache.json`. При рестарті скрипт миттєво підтягує вже оброблені рядки.

4. Вихідні файли:
   Python генерує 3 файли у папку `output/`:
   - 31.xlsx (товари з SEO)
   - hid_specifications.xlsx (характеристики)
   - categories_seo.xlsx (SEO категорій)


ЧАСТИНА 2: PHP (OpenCart Controller)
-----------------------------------------------------------------------------
Шлях: admin/controller/tool/import.php
Бібліотека для Excel: PHPExcel (потребує багато RAM, налаштовано `cache_to_phpTemp`).

1. Імпорт товарів (`importProducts`):
   - Перед імпортом всім товарам з міткою `is_import=1` ставиться status=0 (вимикаються).
   - Товари, які є у файлі, оновлюють price, quantity та вмикаються (status=1).
   - Курс валют оновлюється автоматично.

2. Імпорт опцій/розмірів (`importOptions`):
   - ВАЖЛИВО: Опції жорстко захардкоджені в контролері. 
     $optionSize = 14; $optionSizeJeans = 15; $optionSizeMotobot = 16; $optionSizeKurtka = 17; $optionSizeShtanu = 18;
   - Якщо ID опцій у базі OpenCart зміняться, їх обов'язково треба оновити в початку класу `ControllerToolImport`.

3. Імпорт атрибутів (`importAttributes`):
   - УВАГА: Перед записом нових атрибутів відбувається `TRUNCATE product_attribute`. Модуль повністю перезаписує характеристики.
   - Атрибути автоматично створюються, якщо їх немає в базі, і прив'язуються до групи `$attrGroupId=7`.

4. Імпорт категорій (`importCategoriesSEO`):
   - Читає `categories_seo.xlsx`.
   - Оновлює Title, Description, H1 для RU (id=3) та UA (id=5) мов.
   - Завантажує картинку за URL (12-й стовпчик) через `file_get_contents`, зберігає в `image/catalog/categories/` та оновлює таблицю `oc_category`.


ЧАСТИНА 3: ФІЛЬТРАЦІЯ (OCFilter 4.8)
-----------------------------------------------------------------------------
Модуль інтегрований з OCFilter. Особливості налаштування для наступних розробників/адміністраторів:
1. Після імпорту бази (атрибутів та опцій) ОБОВ'ЯЗКОВО потрібно зайти в налаштування OCFilter -> "Копирование фильтров" і скопіювати Опції та Атрибути. Без цього фільтр на сайті буде порожнім.
2. В OCFilter розділювачем для мульти-атрибутів (наприклад: "Джинс; Текстиль") призначено крапку з комою (`;`). Це налаштовується в параметрах фільтра.
3. Щоб фільтри батьківських категорій відображалися у дочірніх, в OCFilter увімкнено опцію "Показывать фильтры родительских категорий".
4. Для чистоти вітрини увімкнено "Скрывать пустые фильтры".


TROUBLESHOOTING (Вирішення проблем)
-----------------------------------------------------------------------------
- Помилка API OpenAI: Перевірте баланс на акаунті OpenAI або правильність API ключа в `.env`. Згенерований кеш лежить у `ai_cache.json`.
- Товари зникають з сайту: Перевірте, чи не імпортували ви випадково обрізаний файл (наприклад, тестові 10 рядків). PHP-скрипт вимикає всі товари, яких немає у файлі імпорту.
